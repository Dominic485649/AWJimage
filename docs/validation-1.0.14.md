## 2026-09-17 修复说明

- 完成菜单双向重建、机器注册残留识别、恢复快照权限识别及普通模式隐藏提权提示遮罩。

- 最后一轮界面改动按维护者要求不运行测试；仅进行正式发行构建、打包和产物完整性核对。早期构建和测试数字保留为历史证据，不作为新构建的测试结果。

## 本轮验证进度

- Windows Release CTest：50/50 通过（提交 `d176a4f`）；Linux Release CTest：29/29 通过（同提交）。
- Windows/Linux 无测试接口发行构建完成；归档已通过 `7z t`、精确成员、解压哈希、版本/帮助检查，Linux `AWJ` 可执行位保留。
- 普通菜单逻辑、隔离 HKCU 安装/迁移/恢复、配置活跃进程排除及真实子进程中断恢复：小型独立构建 3/3 通过。
- 资源规划、流水线安全与取消：Debug 定向回归 3/3 通过；不代替最终 Release 验收。
- 原生注册表事务方案已撤回：本机 Windows 10.0.26200 对真实 HKCU、显式句柄和隔离映射三种调用均返回 6801（ERROR_RM_NOT_ACTIVE）。探针位于 build/tx-probe-src，未修改系统配置。发行实现改用受保护的 HKLM 快照和提交记录，不能引用早期 KTM 构建作为验收结果。
- 真实列宽指针测试已修正重复执行时未重置宽度的问题，并在 Windows Release 回归中通过。

## 审阅发现

| 优先级 | 发现 | 验收要求 |
| --- | --- | --- |
| P1 | PR #5 从用户可写 HKCU 事务数据恢复 HKLM 内容 | 提权路径不信任用户快照，固定注册白名单；篡改和中断测试 |
| P1 | PR #5 提权后直接使用 helper 的 HKCU，跨账号凭据会修改错误用户 | 原进程保持用户注册所有权；helper 仅写 HKLM |
| P2 | PR #5 在 UI 线程无限等待 helper | 后台执行，有界 IPC，取消/异常恢复 |
| P1 | 1.0.14 未包含 1.0.13 后续修复，VERSION 仍为 1.0.12 | 完整整合，实际二进制版本与源码一致 |
| P2 | Linux 未绑定共享队列新指针回调，无法打开详情 | 双平台按下/松开/拖动/失败过滤回归 |
| P2 | Windows 强制关闭忽略终止失败，仍隐藏窗口 | 失败保持可见，成功后完整清理 |
| P2 | 队列插入与路径集合更新不是异常安全的 | 分配失败时集合和队列保持一致 |
| P2 | 列宽手柄使用随自身移动的局部鼠标坐标 | 连续实际拖动回归 |
| P2 | 调度先领取再等待，大图可阻塞后续可准入小图 | 预算内回填、取消唤醒、溢出及异常释放回归 |

上述为源码审阅发现，不代表全部已经修复或经过动态复现。
