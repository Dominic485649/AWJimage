# AWJimage 1.2.2

本次更新修复 Windows 界面圆角区域中的文字模糊，重点改善高 DPI 下的小字清晰度，并完善真实渲染与缩放回归。编解码行为和平台要求保持不变。

## 修复

- 修复 150% 等缩放比例及部分 200% 布局下，队列统计等圆角区域内的文字发虚。问题来自 Slint/FemtoVG 圆角离屏图层在分数物理坐标上的再次采样，现将纹理、裁剪路径和覆盖区同步对齐物理像素。
- 保留原始裁剪边界，避免对齐后的内容越过父图层缓存范围。不改变字体、字号、字重、圆角或应用的高 DPI 感知方式。
- 未加载 MacType 时也能复现上述问题，修复后的原生字形检查在 MacType 模块保持加载时通过。本次不要求关闭 MacType，也不修改其配置。

## 维护与验证

- 配置时重新应用幂等 Slint 补丁，避免已缓存的依赖源码遗漏修复。Slint 仍固定为 1.18.1，未升级编解码器依赖版本。
- 新增真实 Winit/FemtoVG 字形与裁剪边界回归，覆盖中英文、矩形裁剪、圆角裁剪、嵌套圆角及父缓存边界。需要桌面和 OpenGL 的检查仅在显式启用时注册。
- 修正缩放回归重复设置同一窗口常量缩放的覆盖缺口。正式界面组件截图使用原生事件循环，检查实际比例、帧尺寸、深浅主题和导航切换。
- Windows 原生验证覆盖 100%、125%、150%、200% 的字形检查，以及鸿蒙黑体、微软雅黑 UI 在 150% 和 200% 下的正式界面组件截图。

本轮自动检查使用进程级 Slint 内容缩放，没有改变 Windows 全局显示缩放。真实系统 DPI 切换和跨显示器移动不在本轮自动验证范围内。

## 使用说明

- Windows x64：Windows 10 或更新版本，CPU 支持 AVX2。使用界面和右键转换时，将 `AWJ.exe` 与 `AWJ.com` 放在同一目录。
- Linux x64：CPU 支持 x86-64-v3，glibc 2.39 或更新版本；安装 fontconfig、FreeType，桌面使用 X11 或 Wayland。
- 解压后保留 `LICENSE` 和 `NOTICE.txt`。1.0.12 及更早版本请手动下载升级。
