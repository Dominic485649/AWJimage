# AWJimage 1.1.0

正式版，2026-09-29。本版统一 Studio 参数与右键菜单预设，补全资源限制和菜单同步，
改进 Linux 原生路径处理，并更新 Release 构建要求。当前验证范围见
[验证记录](https://github.com/Dominic485649/AWJimage/blob/master/docs/validation-1.1.0.md)。

## 发布概述

参数设置现在通过同一个下拉框切换“内置默认”“右键菜单”和用户预设。右键菜单预设
拥有与默认预设一致的常用参数、资源限制和格式高级选项，并单独显示同级的
“右键菜单选项”。已注入的用户预设也可以保存菜单选项及相关编码参数；
队列仍只使用普通用户预设。

## 主要变化

- **右键菜单与预设**：内置默认也显示安装、移除按钮，但保持禁用。右键菜单和用户
  预设可设置视觉质量、线程及内存限制；从用户预设安装菜单时只注入已经保存的参数。
  点击“额外添加 .png 后缀”会保存选择并同步已安装的菜单；尚未安装时不主动注入，
  操作失败则恢复原值。
- **参数界面**：AVIF 仅使用 AOM，移除多余的编码器选择；速度栏直接显示默认值 5。
  编辑格式与位深行的标签和控件按资源限制行垂直居中，分组间距一致。长说明最多显示
  四行；最窄窗口下队列命名按钮保持单行，参数页操作按空间换行。
- **路径与队列**：拖放改用结构化文件路径。Linux 的导入、去重、输出命名、冲突处理
  和 CLI 保留原生路径字节，支持含空格、换行或非 UTF-8 字节的文件名。Windows 开始
  转换时直接构建编码输入，避免复制整份界面队列；100k 项开发样本的私有内存峰值
  减少约 50.6 MiB。
- **界面与更新**：Slint 升级至 1.18.0。设置页可手动检查更新，检查期间禁用重复
  操作；字体列表鼠标悬停不再牵动滚动位置。Windows 仅在新版本通过启动健康检查且
  更新事务提交后清理旧更新内容，普通启动、失败和回滚均不清理。
- **发行构建**：Windows Release 最低要求 AVX2，Linux Release 最低要求
  x86-64-v3；两平台均启用 IPO/LTO。AVIF 的色彩、HDR、色度、Grid 与无损路径
  语义保持不变。

## 依赖与构建

Windows 程序由 MSVC（Visual Studio 18 2026）x64、
`x64-windows-static` 构建；Linux 程序由原生 Linux 文件系统中的 GCC 16.1、
`x64-linux` 构建。两平台固定 Slint 1.18.0，Release 均启用 IPO/LTO 且关闭
测试接口（`BUILD_TESTING=OFF`）。发行验证中，Windows 非侵入式 CTest
52/52、Linux CTest 33/33 通过。

源码提交 `26b07c852fe2a51ad7a0bdb796ab7b89b16f8f3d`（tag `1.1.0`）。
